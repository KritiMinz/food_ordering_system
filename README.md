# Food Ordering System

## Project Description

A full-stack Food Ordering System developed as an individual capstone project.

The project combines:

- React frontend
- Tailwind CSS
- C++17 backend
- Object-Oriented Programming
- HTTP/JSON communication
- File-based persistence
- Linux system programming
- Linux device driver
- Git/GitHub

## Architecture

React Frontend
        |
        | HTTP/JSON
        v
C++ Backend
        |
        +---- File-based Storage
        |
        +---- Linux System Programming
        |
        +---- Linux Device Driver
